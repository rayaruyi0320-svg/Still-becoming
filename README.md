# Still Becoming

## Function

A website that randomly resurfaces fragments of unfinished creative work, allowing them to be seen and valued without requiring them to be completed.

## Value

Unfinishedness

## Concept

Unfinished work is not worthless. A paused vlog, an unfinished recording, or an early design can already hold ideas, effort, and moments worth keeping. This project explores unfinishedness as a state of openness rather than failure.

Still Becoming gives attention to creative work that is often hidden because it is not considered ready to share. The planned website will bring one fragment back into view at a time, inviting visitors to notice what is already valuable in it. A work may be revisited or continued when inspiration returns, but finishing it is never a condition of its value.

“You don’t have to finish this now. But you don’t have to lose it either.”
